# ZAO DEVZ

The builders of **The ZAO**, a music and culture community on Farcaster. We ship open tools for artists, fractals and festivals.

**Site:** [thezao.com](https://thezao.com) · **Live:** [zaostock.com/live](https://zaostock.com/live)

## Projects

### Community and governance
| Project | What it is |
|---|---|
| [ZAOfractal](https://github.com/ZAODEVZ/ZAOfractal) | The weekly Respect Game, Mondays 6 PM ET since August 2024. Live at [fractal.thezao.com](https://fractal.thezao.com) |
| [ZAOcowork](https://github.com/ZAODEVZ/ZAOcowork) | The ZAO ops tracker: one Kanban board plus a Telegram bot, live at [thezao.xyz](https://www.thezao.xyz) |
| [ZAOmemberz](https://github.com/ZAODEVZ/ZAOmemberz) | One profile per member, anchored to a wallet, readable by every ZAO app |
| [ZAO101](https://github.com/ZAODEVZ/ZAO101) | Learn The ZAO: music first, community second, tech third |
| [theZAOZone](https://github.com/ZAODEVZ/theZAOZone) | A digital third space to grow, learn and build |

### Tools for builders
| Project | What it is |
|---|---|
